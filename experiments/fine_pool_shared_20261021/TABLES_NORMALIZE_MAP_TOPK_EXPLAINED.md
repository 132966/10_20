# tables、normalize 和 map_topk：结合一个输入例子理解精筛流程

这三个算子分别负责：**打分前准备输入 → 打分后整理分数 → 选完后找回原位置**。

完整顺序是：

```text
tables
  ↓
精筛打分算子
  ↓
normalize
  ↓
TopK
  ↓
map_topk
  ↓
attention 读取选中的 K/V
```

下面用一个示意例子说明：一个 Q 的历史粗筛选中了 **2 页，共 128 个候选槽位**，还要加入 **2 个 sink token 和 33 个尾部 token**。每页可以存 64 个 token。以下编号均从 0 开始，位置按当前索引空间计数；若下游需要位置展开，应按对应接口处理。

## 1. tables：告诉精筛去哪里读，以及读多长

它生成这个 Q 的精筛页表：

```text
[历史页 A，历史页 B，公共 sink 页，公共 tail 页]
```

这里只是**写页编号，不复制 K**。公共数据之前已经准备好了。

假设尾部从页边界开始，则布局为：

```text
历史候选       sink 所在页             tail
128 个槽位     64 个槽位               64 个槽位
               只有前 2 个有效         前 33 个有效，后 31 个为填充
```

因此产生两个长度：

| 输出 | 本例 | 含义 |
|---|---:|---|
| 打分长度 | 225＝128＋64＋33 | 打分算子需要遍历的布局跨度，包含中间填充 |
| 紧凑候选长度 | 163＝128＋2＋33 | 去掉 sink 填充后，用于后续选择的布局长度 |

**紧凑长度也不代表全是合法候选，历史槽位还需要过滤。** sink 和 tail 都按页存储，都可能有填充。本例 tail 起点页对齐，最后 31 个槽位在打分长度之外，所以物理页总容量为 256，打分跨度仍是 225。

如果 tail 从页内偏移 10 开始，仍有 33 个有效位置，则该页为：

```text
[10 个前置无效位置 | 33 个有效 tail 位置 | 21 个末尾填充位置]
```

此时打分跨度为 `128＋64＋10＋33＝235`，紧凑候选长度仍为 `128＋2＋33＝163`。tail 开头的 10 个无效位置需要在分数整理时跳过；末尾 21 个槽位在打分长度之外。

## 2. normalize：把分数整理成能直接做 TopK 的形式

精筛打分后，分数对应刚才的分页布局：

```text
[128 个历史分数 | 2 个 sink 分数＋62 个填充分数 | 33 个 tail 分数]
```

`normalize` 做两件事：

- 去掉布局填充，整理成紧凑顺序：包括 sink 填充，以及 tail 起点不对齐时的前置无效位置；打分长度之外的末尾填充不进入候选。
- 检查历史成员的原逻辑位置，把未来位置、与 sink/tail 重叠等不合法候选的分数设为 `-∞`。

输出变成：

```text
[128 个历史槽位分数 | 2 个 sink 分数 | 33 个 tail 分数]
        ↑
其中非法历史成员已置为 -∞
```

过滤历史成员时，通常保留其候选槽位，将分数设为 `-∞`；因此这里的“紧凑”指去掉分页布局的填充，不是把所有非法历史槽位再次压缩删除。

**它整理的是索引打分，不是做 softmax，也不是归一化概率。**

## 3. map_topk：把选中的候选编号还原为原序列逻辑位置

TopK 返回的是上述紧凑数组里的编号。例如：

```text
TopK 选中：候选编号 70
```

编号 `70` 不是原序列的第 70 个 token。假设：

```text
候选 70
  ↓ 70 // 64 = 1，70 % 64 = 6
位于第二个历史候选页，页内偏移 6
  ↓ 通过候选页表定位该页，再读取 members
成员映射查到：原序列逻辑位置 4200
  ↓ 4200 // 64 = 65，4200 % 64 = 40
原序列逻辑页：65，页内偏移：40
```

这里说明到原序列的逻辑页及页内偏移即可，`4200` 是说明映射关系的假设值。（读取 K/V 时再通过当前请求的页表定位原生物理页；若接口要求，现有实现也可继续转换为原生物理 slot。）

对于 sink 和 tail 候选，其原逻辑位置可以按区间起点直接计算，再表示为逻辑页及页内偏移。

## 三者的区别

| 算子 | 最直接的作用 |
|---|---|
| `tables` | **安排去哪些页打分** |
| `normalize` | **整理分数，排除不能选的位置** |
| `map_topk` | **找回原序列逻辑页及页内偏移**（按接口需要继续转换为物理 slot） |

这份讲解对应共享精筛布局中的独立处理链，不表示上述步骤已经全部融合成一个 kernel。
